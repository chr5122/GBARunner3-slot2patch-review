## 两组模型结果分开看

- **patch B3：** 绿宝石八地址配置三次翻卡，R1 60/81/127 → B3 38/37/37 模型帧。首次 `mapNewBlock` 24219 → 1376。
- **save G1S+B3：** 绿宝石八地址配置首次翻卡，G1S 63 → G1S+B3 41 模型帧；关闭 JIT 两者均为 41。
- 两组对照父本和运行方式不同，不拿 38 与 41 横向宣传某种模式更快。
- 关闭 JIT 仍可能大量经过原生 BX 快捷处理；该对照不能单独量化纯回退开销。
- 模型中 SD 写入/Flash 变化为零，意味着那组回放没有保存验证，不意味着实际卡带保存必然通过。
