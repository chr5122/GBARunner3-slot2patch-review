## 启动方式已核实的区别

- **patch B3：** 保留无占位 ROM 启动，原版 ROM 来自 Slot-2 卡带，SD 提供外挂补丁/PRE。
- **save G1S+B3：** 菜单传入要运行的 ROM 路径；无参数时回退到根目录 `/rom.gba`，这必须是完整游戏。多游戏通过菜单传路径，无需都叫 rom.gba。
- save 分支的 Game Code 不匹配时会取消 Slot-2 保存、回退到 SD 路径，所以能进入游戏不等于已经验证卡带共档。
- 教程面向现有已成功环境的升级，不自动更改 TWiLight 配置，也不虚构不同菜单版本的加载器路径。

## 源码构建核对

save 对应源码由 G1S 父本加既有 B3 差异恢复。核对构建后 ARM9、ARM7 可执行段以及菜单 banner 与测试文件一致；完整 NDS 仍有两个文件头区域合计 40 字节差异。因此记录为代码段重现，不声称全文件同哈希复现，也不替换已实测原文件。
