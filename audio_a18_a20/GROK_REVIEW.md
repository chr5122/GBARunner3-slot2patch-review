## 1. 二进制差异（独立反汇编）

- 全文件仅 **34** 字节不同（作者报告写 33，差 1；窗口还原后全文一致，确认无窗外改动）。
- 文件窗口：`0x3327C`（40 B，VA `0x03805EB4`）、`0x33330`（8 B，`0x03805F68`）、`0x333B8`（8 B，`0x03805FF0`）。ARM7 加载基址 `0x03800000` ↔ 文件 `0x2D3C8`。

### `0x03805EB4` 静音恢复入口（A20）

```
ldr   r0, [pc, #0x1bc]     ; -> 0x03809B4C 声道状态
cmp   r2, #0               ; r2 = 旧 NR32 档
ldreq r2, [r0]
tsteq r2, #4               ; 仅旧档为 0 时测 bit2（波形声道活动）
ldrne r2, [r0, #-0x558]    ; -> 0x038095F4 当前 PCM 编码档 EncLevel
cmpne r2, r1               ; r1 = 新档
strne r1, [r0, #-0x558]
movne r0, r1
blne  0x03804D54           ; 既有 reencodeWave
b     0x03805D9C           ; 原增益出口（先重建再开音）
```

条件链含义：

| 场景 | 行为 |
|---|---|
| 旧档 ≠ 0（非零直接换档） | 不走 `ldreq/tsteq`，直接比 EncLevel，不同则重建（与 A19 非零路径同目标） |
| 旧档 = 0 且声道**不**活动 | `tsteq` 后为 EQ，跳过重建，只落到增益出口 |
| 旧档 = 0 且声道活动且 EncLevel ≠ 新档 | **新增**：重建后开音 |
| 旧档 = 0 且声道活动且 EncLevel = 新档（同档恢复） | 不重建，只开音 |

A19 对照：旧档为 0 时 `beq 0x03805D9C`，**直接跳过重建**——与 mute_cross 一直播旧档一致。

### 50% / 100% 分支（`0x03805F68`、`0x03805FF0`）

- A19：`ldr r1, [pc, …]` / `str r0, [r1, #8]`——写增益时**覆盖** r1（新档选择子）。
- A20：改为 `ldr ip` / `str r0, [ip, #8]`，**保留 r1**，再 `b 0x03805EB4`。
- 75% 分支未改（本就不占用 r1）。`0x03805D9C` 增益出口与 `0x03804D54` 重建入口字节级未改。

**结论：** 补丁范围与语义符合「旧档为 0 ∧ 声道活动 ∧ 目标编码 ≠ 缓冲编码 → 先重建再开音」；同档恢复、非零换档、声道停止路径符合预期。

## 2. `50% → 静音 → 25%`（独立从寄存器/采样重算）

两组事件：低频常量（rate 434，pattern 全 8）与彩幽市三角波（rate 1798）。完整缓冲圈 = `buffer_loop_ms`。

| 组 | 版 | 开音 gain_on_ms | 最后旧档 last_wrong_ms | 稳定新档 clean_tail_start_ms | 缓冲圈 loop_ms | 圈内？ |

- A20 可区分旧档混音采样：常量 549、三角 121（其后分别为 6033 / 6461 新档）。
- **播放相位：** A19/A20 的 PSG3 读头列（采样表列 2/8/14/20）**完全相同**；两组开音相位分别为 26/26 与 0/0。
- **额外静音：** 无；开音时间与 A19 同量级。三角组 A20 开音晚约 **0.031 ms**（一拍混音粒度），可接受。
- **跨恢复窗口最大相邻跳变**（含开音）：常量 256、三角 1792，A19=A20。
- **单独量化「旧波形→新波形」接缝**（`old_only` 后紧接 `new_only` 的相邻混音步）：两组均为 **256**。常量组开音跳变也是 256；三角组开音跳变 1792，接缝 256 **明显小于开音跳变**，未被盖过。
- 稳定后已路由步幅：常量 0；三角 1024（目标波形自身斜率，非异常咔声指标）。

**结论：** 静音后换档已修好；稳定时间与待复核值 16.84 ms / 3.76 ms 一致，且均 ≤ 1 完整缓冲圈。
