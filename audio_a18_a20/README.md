# A18–A20 波形声道实验归档

A20 是 A18、A19 改进的累积版本，三个文件在此合并归档，保留 A18、A19 供对照。它们均为 PATCH 模式测试包，不替换 A17 或已有稳定基线。

- **A18**：按音量档位量化波形声道采样。
- **A19**：在 A18 基础上处理播放过程中的非零音量换档。
- **A20**：在 A19 基础上补充活动声道从静音恢复到不同档位时的波形重建。已预取的数据仍需播放完，效果并非瞬间切换。

## 测试与局限

电脑回放和独立复核支持 A20 的静音恢复改进，详见 `A18_A19_RESULT.md` 和 `GROK_REVIEW.md`。原测试中“最短波形周期”与“完整播放缓冲圈”是不同指标，解读请以两个报告的后续复核为准。A20 尚无 NDSL 实机听感确认；不代表全部游戏已经通过兼容性验证，也不保证与真实 GBA 完全一致。

目前可核验的 A18、A19 输入是编译好的程序，本归档不包含它们对应的完整源码。A20 是对锁定 SHA-256 的 A19 二进制进行定点修改，并非从 A17 源码重建；`build.py` 和 `nr32_resume.s` 记录该步骤，需 ARM 交叉汇编工具。独立复核确认 A19 与 A20 有 34 字节不同。若需将这项功能合入可维护的源码主线，仍需取得对应源码并重新实现、验证。

GBARunner3 原作者及贡献者、Wokann 分支作者的工作是本实验的基础，感谢各位原作者。项目许可证与原项目保持一致；本目录不包含 BIOS、游戏 ROM、存档或个人录音。

文件校验见 `SHA256SUMS.txt`。
