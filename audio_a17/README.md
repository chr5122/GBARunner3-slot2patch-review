# A17：PATCH PCM 自适应音频测试版

上传日期：2026-11-04。此文件与此前 iCloud 的 `A17_PCM_ADAPT_TEST.nds` 完全一致，只改下载文件名，没有重新编译。

**[下载 NDS](GBARunner3_PATCH_A17.nds?raw=true) · [下载运行包 ZIP](GBARunner3_PATCH_A17.zip?raw=true) · [源码快照与冻结构建输入](A17_SOURCE_SNAPSHOT.zip?raw=true)**

模式：**slot2patch / PATCH**。这是独立社区音频测试版；没有将 A17 合入现有代码主线或向上游提 PR，不适用于直接替换 SAVE 模式运行器。

## 这版改进了什么

- 继承该测试线原有 H1、SR2、A2 及前置改进，并保留 A16 的波形步进 17→16。
- PCM 根据游戏定时器、SOUNDBIAS 与声道路由选择支持的重建路径；不分析歌曲音高，不需要逐游戏填写音乐采样率。
- 对支持的非整比输入进行子采样平均；同定时器的单声道/立体声有快速路径，其他情况保留回退。
- 输出仍沿用原线程输出率；没有把游戏 PCM 源采样率提高，也没有扩大声音线程缓冲。

## 如何使用

面向已经能正常运行 PATCH 模式的用户：

1. 下载 `GBARunner3_PATCH_A17.nds`，放到烧录卡中，用独立文件名保留当前能用的 NDS 以便回退。
2. 沿用现有 BIOS、JSON、汉化补丁与 PRE，按原有成功启动方式运行这份 NDS。
3. PATCH 模式继续使用 Slot-2 对应原版卡带；本包不替用户生成或更换游戏汉化资源。

首次配置请参考 [PATCH 模式说明](../docs/PATCH.md)。本次不自动更改 TWiLight 配置或存档文件。

## 验证状态

- **用户实机试听反馈：** 此前上传的同一 A17 文件在 NDSL / iTouchDS 的既有 PATCH 环境试听，用户反馈音质提升、更顺耳，同时感觉音量略小、与原生仍有细微差异。这是用户反馈，不是代理亲自测量，也没有从烧录卡重新读取文件核对哈希。
- **电脑验证：** 受控输入状态核对、45000 组普通输入、15000 组寄存器更新注入及 2048 组已链接 ARM7 指令检查通过。注入试验中 411 组允许一个即时回退样本不同，不能写成所有更新点逐样本等价。
- 开场、标题、对战开拓区的模型回放完成。音频热函数约 402→232 个模型时钟，原 A16 约 252；这不是实机 CPU 或游戏帧率承诺。
- 已定位的一字节差异是正常 RNG 调用计数，额外一次来自片头特效；没有修改随机数逻辑。不能将全部画面相位差异或所有游戏时序宣称无害。
- 尚未完成多游戏、多烧录卡、长时间、保存/重启/原生读档的 A17 专项全面验收。

## 已知限制

A17 未加入后续 M1/M2/M3 波形量化候选。那些候选的静音恢复、首次编码及换档 FIFO 风险不属于本次上传内容。A17 仍存在受控弱波形与软件参考的取整差异；不承诺与 mGBA 或原生 GBA 模拟输出完全相同。NR52/包络相位的延期研究也没有合入。

本版本未修改设备时钟、电源、固件、存档/Flash 路径，也未新增运行期 SD 日志。运行包只含运行器与说明，不含游戏 ROM、BIOS、存档、汉化补丁或 PRE。
